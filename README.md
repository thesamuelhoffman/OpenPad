# OpenPad

A lightweight Linux text editor with a familiar tabbed Notepad-style interface. Built with Python 3 and Tkinter.

## Install

On Ubuntu, Debian, or Linux Mint, install Tkinter if it is missing:

```bash
sudo apt install python3-tk xdg-utils
```

From the project folder:

```bash
./install.sh
```

Launch OpenPad from your applications menu, or run `~/.local/bin/openpad`.

## Make OpenPad your default `.txt` editor

```bash
./set-default.sh
```

## Run without installing

```bash
./launch.sh
```

## Features

Tabbed text editing, file operations, find and replace, keyboard shortcuts, word wrap, line endings, encoding options, light and dark themes, and unsaved session recovery.
